Façade-X as a W3C specification

The W3C Data Façades Community Group is writing Façade-X up as an open specification, so that other engines can implement the same model and give the same answers. SPARQL Anything is the reference implementation.

Release {{ site.spec.version }} of the specification was published on 6 October 2026. Anyone can join the group, comment on the drafts or contribute test cases.
