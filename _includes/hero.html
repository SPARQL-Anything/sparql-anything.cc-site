Query any file with SPARQL

SPARQL Anything reads CSV, JSON, XML, spreadsheets, HTML, Markdown and other formats as RDF. You query them, and build knowledge graphs from them, with plain SPARQL 1.1. There is no mapping language to learn and no conversion step.
