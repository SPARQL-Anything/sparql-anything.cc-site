Get started

You need Java {{ site.release.java }} or later. This turns a CSV file into schema.org triples.

  1. Download the command-line tool

    curl -L -O https://github.com/SPARQL-Anything/sparql.anything/releases/download/v{{ v }}/sparql-anything-v{{ v }}.jar

    Or pick a jar from the release page. The -geosparql variants add GeoSPARQL support.

  2. Write a query

    Save this as query.rq, next to the people.csv file from the example above.

    PREFIX xyz:    <http://sparql.xyz/facade-x/data/>
PREFIX schema: <https://schema.org/>

CONSTRUCT {
  ?person a schema:Person ;
    schema:name ?name ;
    schema:homeLocation ?city .
} WHERE {
  SERVICE <x-sparql-anything:location=people.csv,csv.headers=true> {
    ?row xyz:id ?id ; xyz:name ?name ; xyz:city ?city .
  }
  BIND (IRI(CONCAT("http://example.org/person/", ?id)) AS ?person)
}

  3. Run it

    java -jar sparql-anything-v{{ v }}.jar -q query.rq
    <http://example.org/person/1>
        a                    schema:Person ;
        schema:homeLocation  "London" ;
        schema:name          "Ada" .

<http://example.org/person/2>
        a                    schema:Person ;
        schema:homeLocation  "New York" ;
        schema:name          "Grace" .

    Use -f to pick another output format, such as nt or jsonld, and -o to write to a file. See the command-line reference.

From Python

pip install pysparql-anything
import pysparql_anything as sa
engine = sa.SparqlAnything()
engine.run(query="query.rq", format="ttl")

The jar is downloaded on first use. See PySPARQL Anything.

As a SPARQL endpoint

java -jar sparql-anything-server-v{{ v }}.jar

Starts a Fuseki server at http://localhost:3000/sparql. Any SPARQL client can send it queries that use SERVICE <x-sparql-anything:…>.

From Java

Use the engine as a library inside Apache Jena. See the Java client example and the documentation.
