Features

Querying

  • Plain SPARQL 1.1. Point a SERVICE <x-sparql-anything:…> clause at a resource and set options in the IRI or as triples.
  • Build knowledge graphs with CONSTRUCT, or get tables with SELECT. Output RDF, RDF-star or tabular results.
  • Join data from several sources in one query by combining SERVICE clauses.
  • A function library for container slots, strings, hashes and building entity IRIs.
  • Query templates: run a query once for each row of a SPARQL result set file, or for values given on the command line.

Reaching data

  • Read a file or URL, inline content, or the output of an external command.
  • Call Web APIs with a full HTTP client: any method, custom headers, authentication.
  • Query files inside Zip and Tar archives, and list the contents of folders.
  • Read from Amazon S3 buckets.

Large files

  • Slicing evaluates the query on one row, array item or element at a time, for CSV, JSON and XML.
  • An on-disk mode keeps the Façade-X graph in Apache Jena TDB2 instead of memory.
  • The command line can stream CONSTRUCT output triple by triple.

Running it

  • Command-line tool and a Fuseki-based SPARQL server.
  • Java library, built on Apache Jena ARQ.
  • Python library with results as RDFLib graphs, pandas data frames or NetworkX graphs.
